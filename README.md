# 🍔 AI Menu Generator
Gerador inteligente de descrições persuasivas para cardápios de delivery, focado em aumentar a conversão de restaurantes.

## 🚀 Tecnologias
* HTML5
* Tailwind CSS
* JavaScript (ES6+)

## 💡 Funcionalidades
* Geração instantânea de copywriting gastronômico a partir do nome do prato e ingredientes.
* Interface responsiva em Dark Mode.
